# Prisma Migrations

This directory contains database migration files generated by Prisma.

## To run migrations:

1. Ensure PostgreSQL is running (see ../docs/DATABASE_SETUP.md)
2. Run: `npm run prisma:migrate`

This will:
- Generate migration files in this directory
- Apply the migrations to your database
- Update the Prisma client

## Migration Files

Migration files will be generated with timestamps and descriptive names:
- `20240920123456_init/` - Initial schema creation
- `migration.sql` - Contains the SQL commands to create all tables

## Manual Migration (if needed)

If you need to create the migration manually, you can run:
```bash
npx prisma migrate dev --name init
```

This will create all the tables defined in schema.prisma:
- municipalities
- users  
- categories
- complaints
- complaint_images
- refresh_tokens
